How it works

Five steps, from question to spoken answer

The same flow whether it's a real phone call or this browser demo.

1

Call in

Farmer dials in (or, in this demo, taps the mic) and asks a question in their own language.

2

System listens

Whisper transcribes the speech and detects which language was spoken.

3

Finds real answers

Hybrid search pulls the closest matching resolved cases from the national KCC dataset.

4

Checked for safety

The draft answer is screened against banned chemicals and unsafe dosage limits.

5

Spoken back

The approved answer is read aloud to the farmer in the language they called in with.

Trust & safety

Grounded answers. Nothing invented.

Built with the same care a Krishi Vigyan Kendra expert would use on a phone call.

⛨

Deterministic guardrail

A rule-based safety layer checks every generated answer against an approved Package-of-Practices table — no banned pesticide or unsafe dosage is ever allowed through, regardless of what the model produces.

◇

Privacy by design

Caller IDs are SHA-256 hashed before storage. Raw voice recordings are deleted immediately after transcription — never retained.

✽

Sourced from real data

Answers are retrieved from actual Kisan Call Centre farmer queries and expert responses, sourced via data.gov.in — not invented by the model.

*Compute cost only — runs on a local open-source LLM (Llama 3.1 via Ollama), no per-call API fees. Built for the UNLEASHLLM Innovation Challenge.
