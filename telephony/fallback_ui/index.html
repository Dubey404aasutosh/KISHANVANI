WORKFLOW

Five Steps from Question to Spoken Answer

Consistent, transparent execution whether triggered by a phone call or this browser sandbox.

1

Call In

Farmer dials the helpline number (or taps the mic here) and speaks naturally.

2

Transcribe

Whisper ASR converts voice to text while determining regional language tags.

3

Retrieve

Hybrid BM25 + dense neural search matches the query to verified KCC resolved records.

4

Guardrail

The generated response is validated against the ICAR Package-of-Practices table.

5

Speak Out Loud

TTS converts the verified text back into clean audio in the farmer's mother tongue.

Deterministic Safety Enforcement

Language models can occasionally suggest obsolete or restricted chemicals. KISANVANI applies a hard deterministic lookup against the government Package-of-Practices table to reject unverified recommendations.
